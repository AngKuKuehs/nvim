## keybindings
### default
K -> show type/signature/doc from lsp
<C>w + h -> move to left pane
<C>w + l -> move to right pane
<C>w + j -> move to up pane
<C>w + k -> move to down pane
<C>w + s -> split hori
<C>w + v -> split verti

### remaps
" " -> <leader>
<leader>pv -> :Explore
<leader>e -> show diagnostic error

### telescope
<leader>pf -> search for files
<leader>ps -> search for word

### undo-tree
<leader>u -> summon undo tree
